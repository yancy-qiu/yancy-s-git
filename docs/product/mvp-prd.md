# 轻记 MVP 产品需求文档

> 状态：原型验证
>
> 版本：V0.1
>
> 更新时间：2026-09-17

## 1. 产品目标

轻记帮助不愿维护复杂系统的个人用户，把临时想到的任务、会议内容、工作进展和用户需求先快速记录下来，再通过 AI 整理为可继续处理的内容。

MVP 需要验证两个核心判断：

1. “先记录、后整理”能否明显降低工作记录成本。
2. Mac 桌面小组件能否成为高频查看和轻量处理入口。

## 2. 核心用户流程

```text
想到一件事
→ 在首页或小组件进入快速记录
→ 输入原始内容，可选日期、时间、优先级和提醒
→ 保存到今天、计划或收集箱
→ AI 提取摘要和下一步行动
→ 用户编辑、完成、恢复、延后或删除
```

## 3. MVP 范围

### P0：必须验证

| 能力 | 用户结果 | 原型验收 |
| --- | --- | --- |
| 快速记录 | 不分类也能立即保存 | 输入内容后一次提交完成创建 |
| 记录类型 | 任务、会议、进展、需求可识别 | 支持手动选择和关键词自动判断 |
| 安排与提醒 | 重要内容可加入具体日期和时间 | 支持日期、时间、优先级和提醒开关 |
| AI 整理 | 原始文字变成摘要与下一步 | 原型模拟整理过程并展示结果 |
| 列表管理 | 用户知道内容现在在哪里 | 支持今天、收集箱、计划、待整理、全部和已完成 |
| 详情编辑 | 信息变化后可继续维护 | 可修改标题、正文、类型、日期、时间、优先级和提醒 |
| 状态操作 | 记录可以被推进或恢复 | 支持完成、恢复、延后到明天、删除与撤销 |
| 桌面小组件 | 不打开完整应用也能浏览和处理 | 展示三条记录，支持直接完成和进入编辑 |
| 隐私与外观 | 桌面内容可隐藏，界面适应使用习惯 | 支持小组件隐私模式及浅色、深色、跟随系统 |
| 本地保存 | 关闭页面后数据仍存在 | 使用浏览器本地存储模拟 Mac 本地数据库 |

### P1：获得反馈后决定

- 首次使用引导。
- 快捷键说明面板。
- 自定义小组件筛选条件。
- 批量整理和批量完成。
- 数据导出。

### 本轮不做

- 真实 AI 模型调用和付费体系。
- 登录、团队协作及跨设备同步。
- 日历双向同步。
- 复杂项目、看板、甘特图和多层子任务。

## 4. 关键规则

- 内容本身是唯一必填项；分类和时间不能阻塞记录。
- 未设置日期的记录进入收集箱；未来日期进入计划；今天及逾期内容进入今天。
- 提醒只有在设置日期时才生效。
- 删除后提供即时撤销，避免误操作造成数据丢失。
- 小组件最多展示三条未完成记录；隐私模式使用“私密记录”代替标题。
- AI 整理失败时保留原始记录，用户仍能编辑和完成。

## 5. 原型验证任务

邀请测试用户独立完成以下任务：

1. 记录一条没有日期的临时想法。
2. 创建一条明天上午的重要任务并开启提醒。
3. 找到待整理内容并使用 AI 整理。
4. 将一条记录延后到明天。
5. 在小组件中完成一条记录。
6. 开启小组件隐私模式。
7. 删除一条记录并撤销。

记录完成率、用时、停顿位置、用户原话和 1—5 分总体评分。出现无法继续、数据丢失或用户不知道下一步的情况，视为阻断问题。

## 6. 进入 Mac 原生开发的条件

- 5 位目标用户完成原型测试。
- 快速记录、AI 整理和小组件三个核心流程没有阻断问题。
- 明确 Mac MVP 的 P0 范围和小组件直接操作。
- 对真实 AI 接入方式、隐私提示和成本上限形成方案。
