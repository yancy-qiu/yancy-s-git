# 轻记 MVP 原型设计说明

> 状态：可用性验证
>
> 版本：V0.1
>
> 更新时间：2026-09-17

## 1. 设计目标

原型以 Mac 为主要使用环境，强调快速、安静和可恢复。界面让用户先写下内容，再逐步出现安排、AI 整理和后续处理能力。

视觉参考 Godly 的编辑式大标题、高对比排版、留白、圆角描边卡片和克制动效，同时保持轻记自己的品牌与信息结构。

## 2. 页面结构

```text
Mac 应用窗口
├── 标题栏：设置、体验反馈
├── 侧边栏
│   ├── 今天
│   ├── 收集箱
│   ├── 计划
│   ├── 待整理
│   ├── 全部记录
│   ├── 已完成
│   └── 桌面小组件预览
├── 主内容区
│   ├── 日期与当前视图标题
│   ├── 快速记录区
│   │   ├── 内容
│   │   ├── 类型
│   │   └── 可选安排：日期、时间、优先级、提醒
│   └── 记录卡片网格
└── 详情面板
    ├── 记录元数据
    ├── 原始内容或 AI 整理结果
    └── 编辑、完成、延后、删除
```

## 3. 关键交互

### 快速记录

- 光标默认可以通过 `⌘N` 进入输入区。
- 默认只显示正文和类型，避免时间设置增加录入负担。
- 点击“安排”后展示日期、时间、优先级和提醒。
- 创建未来记录后自动进入计划视图，保证新内容立即可见。

### AI 整理

- 待整理记录用省略号状态提示原始内容仍未处理。
- 点击“用 AI 整理”后显示短暂处理状态。
- 结果包含摘要和三条下一步行动；原始内容始终保留。

### 状态操作

- 卡片圆形按钮用于完成或恢复。
- 详情支持延后到明天。
- 删除后使用底部提示条提供撤销，不增加确认弹窗。

### 桌面小组件

- 展示最多三条未完成记录。
- 圆圈按钮直接完成；标题进入主应用详情。
- 隐私模式隐藏具体标题，但保留条目数量和操作结构。

## 4. 视觉规范

| 项目 | 规则 |
| --- | --- |
| 字体 | 系统字体用于正文和操作；Georgia 斜体只用于品牌字标 |
| 色彩 | 黑白和中性灰为主体；类型标签使用低饱和辅助色 |
| 圆角 | 卡片 16px、主要弹窗 20px、按钮 9—11px |
| 间距 | 以 4px 为基础单位，主要内容间距使用 16、24、32、48px |
| 阴影 | 只用于窗口、浮层和聚焦状态，避免装饰性阴影 |
| 动效 | 150—250ms；只解释悬停、聚焦和状态变化 |
| 可访问性 | 状态同时使用文字、形状和颜色；支持减少动态效果 |

## 5. 响应式规则

- 大于 1050px：侧边栏、主内容和详情三栏同时展示。
- 721—1050px：侧边栏与主内容保留，详情以浮层打开。
- 720px 及以下：隐藏侧边栏，记录卡片改为单列，详情以浮层打开，快速记录操作换行。

浏览器响应式布局用于方便分享和测试；正式 MVP 仍以 Mac 原生窗口与桌面小组件为首发目标。

## 6. 已覆盖状态

- 默认、悬停、聚焦和选中。
- 待整理、AI 整理中、已整理。
- 今天、未来、收集箱和逾期。
- 未完成、已完成和恢复。
- 空列表。
- 删除与撤销。
- 浅色、深色和跟随系统。
- 小组件公开内容和隐私内容。

## 7. 原型边界

- AI 整理为本地模拟，不代表最终模型质量和等待时间。
- 提醒只演示设置状态，不触发浏览器或系统通知。
- 数据只保存在当前浏览器，不代表正式同步与备份方案。
- 小组件预览用于验证信息与操作，正式实现受 WidgetKit 尺寸和刷新机制约束。
