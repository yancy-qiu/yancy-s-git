# 轻记 MVP 原型验收记录

> 状态：已通过内部验收
>
> 版本：V0.1
>
> 更新时间：2026-09-17

## 1. 验收环境

- 桌面浏览器：Mac 风格三栏布局。
- 响应式视口：390 × 844。
- 数据：浏览器本地存储。
- 发布方式：私有 Sites 预览。

## 2. 功能结果

| 场景 | 结果 | 证据 |
| --- | --- | --- |
| 无日期快速记录 | 通过 | 创建后自动进入收集箱，详情立即可见 |
| 日期、时间、优先级、提醒 | 通过 | 创建“明天 09:30”的重要记录，详情显示提醒已开启 |
| 未来计划 | 通过 | 创建未来记录后自动切换到计划视图并显示新记录 |
| 自动分类 | 通过 | 含“会议”内容自动归为会议 |
| AI 整理 | 通过 | 待整理记录经过处理后展示摘要和三条下一步 |
| 完成与恢复 | 通过 | 列表和已完成数量同步更新，可从已完成恢复 |
| 延后 | 通过 | 详情操作将记录日期调整为明天并更新列表 |
| 删除与撤销 | 通过 | 删除后底部提示条在 6 秒内提供撤销，记录按原位置恢复 |
| 完整编辑 | 通过 | 标题、正文、类型、优先级、日期、时间和提醒均可编辑 |
| 小组件直接完成 | 通过 | 点击小组件圆圈后条目移出，主列表状态同步 |
| 小组件隐私 | 通过 | 开启后标题替换为“私密记录” |
| 主题 | 通过 | 深色主题主界面、详情和设置弹窗均可辨识 |
| 数据持久化 | 通过 | 刷新后记录、完成状态和设置保持 |
| 删除全部后的空状态 | 通过 | 空数组不会重新注入示例数据，显示可继续操作的空状态 |
| 移动端导航 | 通过 | 390px 视口可切换六个列表并打开小组件预览 |
| WebMCP | 通过 | 读取与创建工具成功注册；有效创建会更新可见状态，空内容被拒绝 |

## 3. 视觉与可访问性检查

- 桌面三栏层级清楚，记录卡片、详情与主要操作可同时查看。
- 深色主题保持文本和按钮对比度，危险操作使用文字与颜色双重表达。
- 720px 以下卡片改为单列，快速记录操作换行，详情默认关闭并在点击记录后打开。
- 所有主要操作都有文本或无障碍名称；状态不只依赖颜色。
- 支持系统“减少动态效果”设置。

## 4. 原型限制

- AI 整理是本地模拟，只验证交互和信息结构。
- 提醒只验证设置、编辑和状态展示，不触发系统通知。
- 小组件是交互预览，正式版仍需用 WidgetKit 和 App Intents 实现。
- 内部验收不能替代目标用户测试；进入 Mac 原生开发前仍需完成 5 位用户的任务测试。
