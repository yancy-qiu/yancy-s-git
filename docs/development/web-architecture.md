## 已确认范围

用户确认网站需要登录及跨设备同步，AI 使用用户自带 Key，首版仅支持 OpenAI 兼容接口。这替代原浏览器原型“不登录、不跨设备同步”的约束；Mac 原生版另行规划。

## 架构

- `web/src/App.vue`：登录、六类任务视图、详情/编辑、AI 对话引用、主题、小组件和移动端布局。
- `web/src/store.ts`：Pinia 状态、Supabase 会话、任务读写、Realtime 订阅和定时同步；演示模式独立存储。
- `web/src/domain.ts`：任务模型、视图规则、日期校验与 AI 结果保护。
- `web/src/ai.ts`：OpenAI 兼容 HTTPS 请求、连接测试、超时和结构校验。
- `supabase/migrations/202611090001_tasks.sql`：PostgreSQL 数据结构、RLS 策略、冲突检测所需的更新时间触发器。
- Vercel 托管 Vue SPA；Supabase 提供邮箱认证和云端数据，无独立自建服务器。

当前所有视图均在单页工作区切换，无需引入路由。登录态由 Supabase SDK 管理。业务数据以服务端写入成功为准，使用更新时间防止旧版本覆盖；不实现自动冲突合并。

## 隐私与边界

模型配置在独立界面编辑，设置主页不展示接口、模型名或密钥。默认在当前浏览器按账号（演示模式单独隔离）记住配置，可关闭记住或清除密钥；退出登录清空内存，重新登录同一账号后恢复本机配置。不写入任务表、Git 或日志。本机持久保存使用浏览器站点存储，同源脚本和设备使用者可能读取，不等同于服务端密钥保险库，也不跨设备同步。任务按 auth.uid() 做数据库隔离，不依赖前端筛选作为安全边界。设置里解释模型请求会发送的内容，浏览器跨域不兼容会明确报错。尚不支持 Claude 独立协议，不使用平台统一密钥。

用户已创建 Supabase 并确认新版网页可打开，真实邮箱和跨设备同步仍待验收。接入、邮件确认、Vercel 配置、同步边界见 `web/README.md`。用户已授权本次修改后推送到 main，触发 Vercel 自动部署。

## AI 空任务兼容修复（2026-11-10）

模型在不执行任务操作时可能返回 `{"action":"none","reply":"追问内容","task":null}`。校验现在接受 task 为 null 或省略，展示回复且不写入任务。create/update 仍必须提供有效任务对象，空值会明确报错并保留原任务。模型提示词同步说明该约定；无效 JSON 或任务字段校验失败会显示可读提示，不再将 Zod 内部错误直接显示在页面。单元测试和浏览器模拟接口均覆盖 null 追问、空任务更新、无效字段及失败不写入。
