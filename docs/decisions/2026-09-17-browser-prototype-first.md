# 浏览器交互原型优先决策

> 状态：已确认
>
> 版本：V1.0
>
> 日期：2026-09-17

## 决策

轻记先制作并发布一个可交互的浏览器原型，用它验证快速记录、AI 整理、编辑与完成、列表筛选和 Mac 桌面小组件预览。收集用户反馈并确认核心范围后，再进入 Mac 原生应用开发。

浏览器原型使用 HTML、CSS 和 JavaScript，实现成本低、分发快。正式 Mac 应用仍使用 Swift、SwiftUI、WidgetKit 和 App Intents；浏览器原型用于验证产品和交互，不要求将其代码直接转换为 Swift。

## 设计参考

原型参考 Godly 的高对比编辑式排版、充足留白、圆角边框卡片、侧边导航和克制动效。参考仅用于提炼设计原则，不复制其品牌、内容或具体页面。

## 验证重点

1. 用户是否能在没有说明的情况下完成一次快速记录。
2. 用户是否理解“先记录、再由 AI 整理”的价值。
3. 用户是否需要在 Mac 桌面小组件中查看和完成近期记录。
4. 用户在哪些步骤停顿，以及最希望补充或删减哪些能力。

## 后续动作

邀请目标用户体验原型，收集评分、停顿点和文字反馈；根据反馈确认 Mac MVP 的 P0 范围，再编写原生应用 PRD 和技术任务清单。
